# 3D 美术资产流程

## 概念与规格

- 确认用途、目标引擎、资产类型、真实尺寸、面数预算和最终交付格式。
- 约定坐标轴、单位、原点位置、命名规范、贴图分辨率和材质槽数量。
- 用简短设定说明资产轮廓、结构关系、表面老化和最重要的辨识特征。
- 保留参考图及授权来源，区分概念图里的渲染效果和需要建模的结构。

## 三视图提示词

- 为正、侧、背每张图复用同一段形体、尺寸比例、颜色和细节锚点。
- 指定正交相机、同一画布比例、相同尺寸标尺、中性背景和均匀光照。
- 明确侧视方向，以及视图间必须一致的接缝、开孔与附件位置。
- 在出模前对齐参考图的地面线和关键高度，记录图间矛盾及采用依据。
- 示例模板：「{资产与尺寸}，{视角}正交视图，{一致结构}，中性背景，完整入画」。

## 程序化建模

- 使用 Blender 自带 Python 环境的 `bpy`，将参数、建模、材质和输出分成独立步骤。
- 先用简单几何体确认比例和轮廓，再迭代拓扑、倒角与UV。
- 为脚本管理的对象使用独立集合和稳定命名，重复运行只更新该集合。
- 核对影响导出的修改器、法线、变换和三角面数，保留可编辑工作文件。
- 使用项目相对路径保存产物，另存输出文件并保留现有源场景。

## 无头渲染复核

- 为正、侧、背及四分之三视角设置命名相机，使用统一分辨率和照明。
- 在脚本中设置相机和各自的输出文件，再逐视角渲染并检查输出存在且非空。
- 可从项目目录运行如下命令，脚本异常时返回非零退出码。

```text
blender --background asset.blend --python-exit-code 1 --python scripts/render_views.py
```

- 核对各视角的比例和轮廓，检查出框、遮挡、反转法线或材质缺失。
- 留存命令、Blender 版本、渲染图和可核对的日志。
- 命令参数和脚本调用参考 [Blender 命令行手册](https://docs.blender.org/manual/en/5.0/advanced/command_line/arguments.html)。

## PBR 与交付验收

- 检查 Base Color、Roughness、Metallic、Normal 和所需 AO 贴图及通道约定。
- Base Color 按色彩贴图读取，法线和数据贴图使用非颜色数据设置。
- 核对 UV 重叠是否有意、像素密度是否一致、贴图路径是否能随资产迁移。
- 在目标引擎重新导入，核对单位、轴向、原点、包围盒和材质槽。
- 汇总源文件、发布资产、贴图、预览图和规格清单，记录未验证项目。
- 报告实测面数、贴图尺寸和各视角结果，注明所用采样与渲染设置。
