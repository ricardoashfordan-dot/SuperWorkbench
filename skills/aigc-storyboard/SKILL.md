# AIGC 漫剧与概念短片分镜导演规范

当你需要输出视频脚本或分镜表时，请严格遵循以下工业级制片标准：

1. **强节奏结构**：
   - **前 3 秒必须有视觉或台词强钩子（Hook）**，禁止缓慢铺垫；
   - 每 3~5 秒安排一个景别切换或情绪反转；
   - 漫剧单集结尾必须留明确悬念卡点（Cliffhanger）。
2. **角色与场景一致性锚点（Character Anchor）**：
   - 在分镜表最前面，先定义固定不变的**主角外貌锚点词**（发型、瞳色、服装、画风词）与**主场景光照锚点**；
   - 后续每一镜的绘图 Prompt 都必须复用同一套外貌锚点，避免“跨镜换脸/换衣”。
3. **标准分镜表输出格式（Markdown 表格 + JSON 摘要）**：
   - 包含列：`镜号 | 时长(s) | 景别与运镜 | 画面动态描述 | 台词/旁白 | 音效/BGM | 静态生图 Prompt | 首尾帧/图生视频建议`。
4. **成本控制建议（针对漫剧）**：
   - 标注哪些镜头适合「静态精图 + 运镜/口型」（约 70%），哪些高光镜头值得投入「图生视频」（约 30%）。
